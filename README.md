## Overview

**QR Code Generator & Downloader** is a cross-platform mobile application built with **React Native** and **Expo**.  
It allows users to **generate customizable QR codes** from text or URLs and **download them as images** directly to their gallery.

---

## Features

- Generate QR codes instantly from text or URLs
<!-- - Customize color and background of QR codes   -->
- Download and save generated QR codes as images
  <!-- - Share QR codes via other apps   -->
  <!-- - Fast, lightweight, and user-friendly interface   -->

---

## Tech Stack

- **React Native / Expo** – cross-platform mobile app framework
- **react-native-qrcode-svg** – for generating QR codes
- **react-native-view-shot** – for capturing views as images
- **react-native-fs** – for saving files to local storage
